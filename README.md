📚 参考文献自动排版工具
还在手动调整参考文献格式？复制一条标准文献，剩下的交给它。

👉 立即使用： https://moonjunjie.github.io/moon/

✨ 为什么推荐给你？
写论文时，最烦人的工作之一就是一条一条地调整参考文献格式。国标、APA、IEEE……不同期刊要求不同，手动改起来不仅耗时，还容易出错。

这个工具就是为了把科研人员从枯燥的格式劳动中解放出来而设计的——纯浏览器运行，无需安装，打开即用。

⚡ 核心功能
功能	说明
一键识别 & 转换	输入一条标准参考文献，工具自动识别其原始格式，并转换为目标样式。
批量处理	支持多条文献同时转换，告别逐条修改。
智能大小写	自动处理题名的大小写规则（如首字母大写、实词大写等）。
期刊缩写智能判断	自动识别期刊缩写是否保留句点，无需人工核对。
联网搜索补全	支持通过题名、作者、年份或 DOI 搜索文献信息，低可信度时提供多个候选供你选择。
三种常用输出格式	生成 GB/T 7714—2015（国标）、APA 7 和 IEEE 三种主流参考文献格式。
多数据源支持	后台调用 Crossref、OpenAlex、Semantic Scholar 和 DataCite 的公开接口，提高匹配成功率。
